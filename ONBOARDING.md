## Your Setup Checklist

### Codebases
- [ ] AeroVisit-Capstone (the Spring Boot app, `AeroVisit_Project/aerovisit`) — https://github.com/pasnormal616-stack/AeroVisit-Capstone
- [ ] AeroVisit-AI (Python service, `AeroVisit_Project/AeroVisit-AI`) — lives alongside the main repo in the same workspace folder

### MCP Servers to Activate
- [ ] ide — the built-in IDE integration (VS Code / JetBrains). Gives Claude live diagnostics from your editor and lets it run code in a connected Jupyter kernel. No credentials needed: install the Claude Code extension in your IDE, then run `claude` from its integrated terminal and confirm with `/mcp`.

### Skills to Know About
- [ ] /plugin — manage Claude Code plugins and marketplaces (install, enable, disable). Used most often here; it's how the design skills below got installed.
- [ ] /design-taste-frontend — anti-slop frontend skill for pages and redesigns. Used when building portal UI that shouldn't look templated.
- [ ] /high-end-visual-design — the fonts, spacing, shadows and animation rules that keep the portals looking deliberate rather than default.
- [ ] /industrial-brutalist-ui — rigid grids and terminal-flavoured styling; the closest fit for the military visitor-management look.
- [ ] /code-review — reviews the current diff for correctness bugs before anything lands.
